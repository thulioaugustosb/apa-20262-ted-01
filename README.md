## Como utilizar o cenário

1. Localize a pasta correspondente ao cenário atribuído à sua dupla.
2. Leia o `README.md` existente dentro da pasta do cenário.
3. Copie os arquivos do cenário para o repositório GitHub que será utilizado pela dupla para desenvolver a atividade.
4. Utilize os arquivos da pasta `dados/` como dados de entrada da solução.
5. Desenvolva o programa Python conforme os requisitos apresentados no enunciado da TED.
6. Não altere os arquivos de dados originais fornecidos neste repositório.

### Estrutura dos cenários

Cada cenário possui a seguinte organização:

```text
cenario/
├── README.md
└── dados/
    ├── arquivo_01.csv
    └── arquivo_02.csv
```

O `README.md` de cada cenário apresenta a descrição do problema e as análises que deverão ser realizadas.

## Repositório da dupla

A solução **não deverá ser desenvolvida neste repositório**.

Cada dupla deverá criar seu próprio repositório no GitHub para desenvolver e entregar a atividade.

O repositório da dupla deverá conter, no mínimo:

```text
ted-01-nome-da-dupla/
├── README.md
├── dados/
└── src/
    └── main.py
```

O link do repositório da dupla deverá ser enviado pelo portal da disciplina até a data definida para a atividade.

## Importante

* Utilize somente o cenário atribuído à sua dupla.
* Não altere os dados originais fornecidos.
* Os dois integrantes devem participar do desenvolvimento da atividade.
* Ambos os integrantes devem conhecer e ser capazes de explicar a solução desenvolvida.
* O GitHub será utilizado como meio de desenvolvimento e entrega. **A quantidade de commits não será utilizada como critério de avaliação.**

Consulte o **enunciado da TED 01 no portal da disciplina** para conhecer os requisitos completos e os critérios de avaliação.
